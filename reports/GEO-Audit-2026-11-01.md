# GEO Audit: pixiedigitalcreatives.com
**Date:** 1 Nov 2026 · **Scope:** live site (https://www.pixiedigitalcreatives.com) + codebase · **Phase 1, no changes made**

GEO (Generative Engine Optimization) = making the site easy for AI search tools (ChatGPT Search, Google AI Overviews, Gemini, Perplexity, Copilot) to **find, understand and cite**. Nothing guarantees an AI tool will recommend a business; these changes remove the obstacles and give the tools clear, quotable, verifiable information.

## What already passes (from the SEO work deployed today)
| Check | Result |
|---|---|
| HTTPS, single host | `pixiedigitalcreatives.com` → 308 → `www` |
| Per-page title + description | 9 unique pages |
| Canonical tags | 1 per page, absolute `www` URL |
| Open Graph / Twitter tags | Present, absolute image URL |
| robots.txt | Valid; blocks `/admin`, `/api/`; links sitemap |
| XML sitemap | 9 URLs; submitted to Google Search Console: **Success, 9 discovered** |
| JSON-LD | Organization + WebSite + page type; BreadcrumbList on inner pages |
| AI crawler access | OAI-SearchBot, GPTBot, PerplexityBot, ClaudeBot all get **200** (no firewall blocking) |
| Semantic landmarks | `<header>`, `<nav>`, `<main>` (every page), `<footer>`; one H1 per page |
| Images | All have alt text |
| Admin | `noindex`, excluded from sitemap |

## Findings by priority

### Critical
1. **Most page content is invisible to AI crawlers.** OAI-SearchBot, PerplexityBot and ClaudeBot do not run JavaScript. In the raw HTML they get: Home 255 words, Services 246, **Pricing 62, About 59, Contact 56, Process 55, Portfolio 45, Company Profile 38, Brochure 33.** The process steps, pillars, project details, prices and founders never reach them.
2. **No page per service.** Website development, app development, social media marketing, model & influencer marketing, SEO, AEO and GEO all share `/services`. An AI answer about "website development agency" has no dedicated page to cite, and there is no `Service` schema per service.
3. **Projects have no URLs.** Portfolio items open in a modal only; there is nothing an AI tool (or Google) can index or cite as a case study.

### High
4. **robots.txt does not separate search crawlers from AI-training crawlers.** Everything is allowed by one `User-agent: *` rule; there is no explicit policy for OAI-SearchBot / ChatGPT-User / PerplexityBot / Claude-SearchBot vs GPTBot / ClaudeBot / Google-Extended / CCBot.
5. **Brand facts are inconsistent.**
   - Phone: CMS / Contact page / footer show **+91 96086 84177**; code defaults and the **Company Profile book** show **+91 97089 76946 / +91 88253 10738**.
   - Address "Digital Studio Worldwide & Remote" is not a postal address (rules out LocalBusiness schema unless a real address exists).
   - Facebook link is a **share link** (`facebook.com/share/…`), not a profile URL; X handle is not declared (`twitter:site`).
6. **No question-and-answer content.** AI answers lift short, direct answers to real questions ("How much does a website cost?", "What is GEO?"). The site has none.
7. **No educational / blog content.** Nothing to cite for informational searches (SEO vs AEO vs GEO, choosing WordPress vs custom, etc.); no `Article` schema.
8. **Structured-data gaps.** Missing: `Service` (per service), `Article`, `CreativeWork` (projects), founders as `Person`, Organization `founder`, `contactPoint`, `telephone`, `areaServed`.

### Medium
9. **`/llms.txt` missing** (returns the HTML app). Optional, not a ranking factor, but cheap.
10. **Soft 404s:** unknown URLs return 200 with the home page (marked `noindex` only after JavaScript runs).
11. **Topic coverage gaps:** "Social media marketing" is never used as a phrase (site says Social Media / Handling / Ads); "Model & influencer marketing" appears only inside Pricing.
12. **Performance:** ~930 KB main JavaScript bundle; nothing is painted until it runs (FCP/LCP ≈ 2.0 s on fast desktop, slower on phones).

### Low
13. Project descriptions are short (21-45 words) and two entries are concept/demo work (**Moti Restro**: client "Demo", described as conceptual; **Ocean Rare**: `-demo` URL). Case studies must label these honestly.
14. Sitemap has no `lastmod` (fine); only 9 URLs (will grow with new pages).

## Plan (Phases 2-5)
| # | Change | Fixes |
|---|---|---|
| 1 | robots.txt with explicit search-crawler and training-crawler groups; `llms.txt` | 4, 9 |
| 2 | Full crawlable HTML for every page (process steps, pillars, team, projects, pricing plans, Q&A) | 1 |
| 3 | 7 service pages `/services/<slug>` with detailed descriptions, Q&A, `Service` + `BreadcrumbList` schema | 2, 6, 8, 11 |
| 4 | Case-study pages `/work/<slug>` from the real CMS projects (concepts labelled), `CreativeWork` schema | 3, 13 |
| 5 | Industry pages backed by real projects; blog with educational articles + `Article` schema | 7 |
| 6 | One source of brand facts (name, URL, email, phone, socials, founders) used everywhere; richer Organization schema | 5, 8 |
| 7 | Validate: JSON-LD parse + required fields, sitemap, robots, canonicals, raw-HTML word counts, browser check | 10 (documented) |

Rules followed: no redesign (new pages reuse the existing design system), no new packages, no invented testimonials, results, awards, addresses or statistics.
